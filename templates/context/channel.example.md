# Channel rules

## Formatting
- Use Slack mrkdwn: *bold*, _italic_, `code`, ```code block```.
- No markdown headers (#), no numbered lists unless explicitly asked.

## Response length
- Max 3 short paragraphs or 6 sentences.
- For tasks: brief confirmation only (status, title, id) + at most 1 follow-up question.
- No "insight" boxes, long explanations, or unnecessary lists.

## Mention commands
- `new` — start a new session (forget previous context)
- `stop` — stop any running agent process
- `session` — show current session info
